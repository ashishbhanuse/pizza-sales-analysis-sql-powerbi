# 🍕 Pizza Sales Analysis using SQL & Power BI

An end-to-end Data Analytics project that analyzes pizza sales data using **MySQL** and visualizes key business insights with **Power BI**. This project demonstrates SQL querying, data analysis, KPI creation, and dashboard development to support data-driven business decisions.

---

# 📌 Project Overview

The objective of this project is to analyze pizza sales data to uncover revenue trends, customer ordering behavior, product performance, and operational insights. SQL is used for data extraction and business analysis, while Power BI is used to create an interactive dashboard for visualization.

---

# 🎯 Objectives

- Analyze pizza sales data using SQL
- Calculate business KPIs
- Identify top-performing pizzas
- Analyze sales trends over time
- Study customer ordering behavior
- Create an interactive Power BI dashboard
- Generate actionable business insights

# ❓ Business Questions Solved

1. Retrieve the total number of orders placed.
2. Calculate total revenue generated from pizza sales.
3. Identify the highest-priced pizza.
4. Find the most commonly ordered pizza size.
5. List the Top 5 most ordered pizzas.
6. Calculate total quantity sold by pizza category.
7. Determine hourly order distribution.
8. Find category-wise distribution of pizzas.
9. Calculate average pizzas ordered per day.
10. Identify the Top 3 revenue-generating pizzas.
11. Calculate percentage contribution of each pizza category to total revenue.
12. Analyze cumulative revenue over time.
13. Determine the Top 3 pizzas by revenue within each category.

---

# 💡 Key Insights

- 🍕 Classic pizzas generated the highest revenue among all categories.
- 📦 Large-sized pizzas were ordered most frequently.
- 🕛 Peak order volume occurred during lunch and evening hours.
- 📈 Monthly revenue fluctuated throughout the year with noticeable seasonal trends.
- 🏆 The Classic Deluxe Pizza ranked among the highest-selling pizzas.
- 💰 Revenue contribution varied significantly across pizza categories.
